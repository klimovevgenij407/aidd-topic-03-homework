## 4. Ключевые технические решения

1. **Абстракция провайдера рыночных данных.** `TinkoffProvider` использует
   официальный SDK invest-python; `SyntheticProvider` даёт детерминированные
   данные для локального запуска и тестов. Режим `auto` выбирает T-Bank при
   наличии токена и SDK, иначе синтетику.
2. **SQLite по умолчанию.** Позволяет запустить приложение без Docker и
   PostgreSQL; PostgreSQL включается через `DATABASE_ENGINE=postgres`.
3. **Management-команды вместо обязательного Redis.** `refresh_prices`
   запускает полный конвейер локально; Celery worker/beat сохранены для
   production.
4. **Единый конвейер обновления:**
   `refresh → PriceSnapshot → alerts → strategies` с уникальными
   ограничениями и транзакциями.
5. **Сервисный слой.** Расчёты портфеля и стратегий отделены от views/API,
   денежные значения — `Decimal`.

## 5. Проблемы и корректировки

| Проблема | Причина | Решение |
|---|---|---|
| Установка исходных зависимостей падает | `grpcio==1.51.3` не собирается на Python 3.13 | Обновлён стек |
| `No module named 'crispy_bootstrap3'` | Шаблоны использовали Bootstrap 5, а crispy — Bootstrap 3 | Переход на crispy-bootstrap5 |
| SDK T-Bank недоступен из индекса | Пакет отсутствует в доступном репозитории | SDK вынесен в `requirements-market.txt`, добавлен синтетический провайдер |
| Нет доступа к git T-Bank | Ошибка проверки TLS-сертификата | Реальный провайдер написан, но не запускался |
| Нет Docker/PostgreSQL/Redis | Среда без инфраструктуры | SQLite + management-команды |
| `basename argument not specified` | DRF ViewSet без атрибута `queryset` | Явные `basename` |
| `?share=abc` мог дать 500 | Нечисловой PK | Проверка `int()` → 400 |
| API-правило стратегии создавалось неактивным | Multipart-семантика DRF для Boolean | `BooleanField(default=True)` в сериализаторах |
| История цен не догружалась при наличии только свежей цены | Слабая проверка покрытия периода | Проверка earliest/latest + допуск на выходные |
| Вручную выключенный алерт автоматически включался | `is_active` не отличал ручное отключение от срабатывания | Повторное взведение только при `triggered_at` |
| Тесты использовали устаревшие объекты | Сервисы работают с заблокированными копиями | `refresh_from_db()` в тестах |
| Локальная проверка цены `100.50` | В `ru-ru` Decimal отображается как `100,50` | Исправлено ожидание теста |

## 8. Ограничения

1. **Реальный T-Bank API не проверен:** нет токена и SDK. Все проверки
   рыночных данных выполнены на синтетическом провайдере.
2. **Docker/PostgreSQL/Redis не запускались:** среда без Docker.
3. **UI проверен через HTTP/HTML-тесты**, без визуального просмотра в браузере.
4. **E-mail** проверен через locmem backend, не через реальный SMTP.
5. **Стратегии** симулируются на поступающих снимках цен; исторический
   backtest не реализован.
6. **Конкурентная нагрузка** не тестировалась, хотя ограничения БД и
   блокировки заложены.
